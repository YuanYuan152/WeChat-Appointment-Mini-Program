# EAP 量表权限与隐私协议 v1

状态：量表定义权限、报告行级隔离、敏感字段分级、访问审计、内容删除、分享扫码与统计均已实现。

量表答案、人口学信息和报告属于敏感个人信息。实现时必须同时满足接口鉴权、数据行级隔离、操作审计和用户删除要求。

## 1. 角色矩阵

| 能力 | 未登录 | Patient | Counselor | Assistant | Ops | Admin |
| --- | --- | --- | --- | --- | --- | --- |
| 查看已发布量表列表/详情 | 是 | 是 | 是 | 是 | 是 | 是 |
| 开始答题 | 登录后 | 是 | 否 | 否 | 否 | 否 |
| 提交报告 | 否 | 仅本人 | 否 | 否 | 否 | 否 |
| 查看/删除本人报告 | 否 | 仅本人 | 否 | 否 | 否 | 否 |
| 查看来访者报告展示内容 | 否 | 否 | 否 | 是 | 是 | 是 |
| 查看原始答案 | 否 | 仅本人 | 否 | 否 | 是 | 是 |
| 查看人口学答案 | 否 | 仅本人 | 否 | 否 | 是 | 是 |
| 新建/编辑草稿 | 否 | 否 | 否 | 否 | 是 | 是 |
| 发布/归档/恢复版本 | 否 | 否 | 否 | 否 | 是 | 是 |
| 查看分享统计 | 否 | 否 | 否 | 是 | 是 | 是 |

说明：

- `Assistant` 只能查看和用户端一致的报告展示内容，不能查看逐题原始答案和人口学答案。
- `Counselor` 默认无权通过后台查看来访者量表报告；后续若有业务需要必须单独提出并评审。
- 管理工作台角色沿用现有 `Assistant < Ops < Admin` 体系，但量表权限不得仅依赖前端隐藏按钮，必须由后端校验。

## 2. 行级权限

1. Patient 只能通过当前 token 对应的 `AccountId` 查询自己的报告。
2. 查询他人报告时返回 `404`，不暴露报告是否存在。
3. 管理后台只能访问来访者账号的报告，不允许通过可枚举 ID 绕过筛选。
4. 对外使用随机 `publicId`，数据库自增 ID 不返回给 EAP 用户端。
5. 分享二维码只指向量表介绍页，不包含报告 ID、答案或用户身份。

## 3. 管理后台展示

- “量表管理”放在运营配置下。
- `Assistant` 在管理端只显示“量表结果”；隐藏并禁止访问“量表管理”和编辑接口。
- “量表结果”页面为 `Assistant`、`Ops`、`Admin` 提供“填写记录 / 分享统计”页签；
  分享统计展示扫码事件、近似独立扫码、分享归因完成和扫码转化率。
- `Ops`、`Admin` 可进入“量表配置”。
- 来访者详情提供“量表记录”入口。
- 从来访者详情查看报告时先关闭当前抽屉，再跳转到按该来访筛选的“量表结果”页面；
  报告详情只使用该页面内的一层抽屉。
- EAP 报告和小程序历史 PHQ-9/GAD-7 必须展示来源标签。

## 4. 审计事件

当前已实现查看详情、敏感内容访问、量表定义变更和删除报告等审计。以下操作存在时必须记录
操作者、目标、时间和结果；尚未实现的导出/下载不得绕过审计直接上线：

- 查看来访者报告详情。
- 查看原始答案或人口学答案。
- 新建、修改、发布、归档和恢复量表。
- 导出或下载报告。
- 删除用户报告。
- 查看或导出分享统计明细。

审计日志不得复制保存完整答案和报告正文，只记录报告 `publicId`、量表 ID、版本和操作类型。

## 5. 用户同意

专业量表提交前必须展示当前隐私协议版本，并记录：

- `consentVersion`
- `consentAcceptedAt`
- `AccountId`
- 量表 ID 和版本

隐私协议至少说明：

- 收集的正式答案、人口学答案和报告内容。
- 数据用于生成报告、账号内同步和授权工作人员查看。
- 保存期限和删除方式。
- 未成年人及监护人要求。
- 分享海报不包含个人测评结果。

协议内容发生实质变化时必须提升 `consentVersion`，不能只沿用浏览器中的旧同意标志。

## 6. 删除和保留

- 用户删除报告后，EAP 与管理后台均不能继续读取报告内容。
- 原始答案、人口学答案、结果和报告快照需要按产品确定的删除策略清除。
- 允许保留不包含内容的匿名审计事件，用于安全追溯。
- 已归档量表的历史报告仍可展示，前提是用户未删除报告。

## 7. 分享安全

- 第一版分享对象是“量表邀请海报”，不是个人报告海报。
- 二维码参数只包含由量表 ID 和独立服务端密钥生成的签名静态 `shareCode`，不包含用户身份。
- 扫码统计不保存明文 IP；无有效 cookie 时生成随机匿名 token 并写入 180 天 HttpOnly cookie，
  再与独立服务端密钥做 HMAC。当前不使用 IP/User-Agent 请求指纹。
- 不允许通过二维码直接打开任何用户报告。
- 分享转化只记录 `shareCode -> report publicId` 的归因关系。

## 8. 需要单独审批的范围

以下变动不得随普通前端功能直接实现：

- 新增或修改数据库表、列、索引。
- Counselor 查看来访者量表结果。
- 将报告结果分享给第三方或生成公开报告链接。
- 批量导出原始答案、人口学信息或报告。
- 修改数据保存期限或删除策略。
- 小程序 WebView 免登录票据及账号自动交换。
