### 错误处理机制
```typescript
try {
  const result = await api.getData()
  if (result.code === 0) {
    // 处理成功响应
    handleSuccess(result.data)
  } else {
    // 处理业务错误
    handleBusinessError(result.msg)
  }
} catch (error) {
  // 处理网络错误
  handleNetworkError(error)
  // 加载备用数据
  loadFallbackData()
}
```

## 📋 后端接口要求

### 1. 响应格式
```json
{
  "code": 0,           // 0表示成功，其他表示失败
  "msg": "success",     // 响应消息
  "data": {            // 响应数据
    // 具体数据内容
  }
}
```

### 2. 必需接口
- `GET /api/home/index` - 首页数据
- `GET /api/search` - 全局搜索
- `GET /api/doctors` - 咨询师列表
- `GET /api/activities` - 活动列表
- `GET /api/live-streams` - 直播列表

### 3. 错误码规范
- `0`: 成功
- `-1`: 需要登录
- `400`: 请求参数错误
- `401`: 未授权
- `500`: 服务器内部错误
