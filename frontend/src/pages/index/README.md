# 首页设计说明

## 概述
这个首页组件参考了原有的Index.cshtml设计，重新实现为Vue 3 + TypeScript的组件。

## 主要特性

### 1. 搜索栏
- 深色背景的搜索输入框
- 右侧搜索图标
- 支持关键词搜索咨询师

### 2. 轮播图
- 自动播放的轮播图
- 每张轮播图包含标题、副标题、时间和按钮
- 支持点击跳转

### 3. 功能卡片区域
- **心理咨询卡片**：主要功能卡片，包含预约咨询按钮
- **月度精华卡片**：显示当月活动数量
- **活动招募卡片**：包含精彩活动按钮
- **心理测量卡片**：心理测评功能入口

### 4. 图标导航
- 往期精华
- 了解咨询
- 关于我们
- 济心理

### 5. 专业咨询师
- 横向滚动的咨询师列表
- 每个咨询师卡片包含：
  - 头像和标签（地面/视频）
  - 咨询时数
  - 姓名、地区、从业年限
  - 专业领域
  - 价格信息

### 6. 活动招募/直播预告
- 两个标签页切换
- 活动列表和直播列表
- 每个项目包含图片、标题、描述、价格和加入按钮

### 7. 底部导航栏
- 首页（当前页）
- 活动招募
- 心理咨询（特殊样式）
- 主题月
- 我的

## 技术实现

### 组件结构
- 使用Vue 3 Composition API
- TypeScript类型支持
- 响应式数据管理

### 样式特点
- 深蓝色主题背景 (#434A76)
- 渐变卡片设计
- 圆角边框和阴影效果
- 响应式布局支持

### 数据管理
- 模拟数据加载
- 支持API数据对接
- 事件处理函数

## 使用说明

1. 确保所有图标文件已复制到 `/static/images/` 目录
2. 更新类型定义文件以支持新的数据结构
3. 根据需要调整样式和布局
4. 对接真实的API接口

## 注意事项

- 图标文件路径需要正确配置
- 响应式设计在小屏幕设备上可能需要进一步优化
- 建议添加加载状态和错误处理
- 可以根据实际需求调整卡片布局和样式
