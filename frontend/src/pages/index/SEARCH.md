# 搜索功能使用说明

## 功能概述

首页搜索栏提供了完整的咨询师搜索功能，包括实时搜索、搜索建议、搜索历史等功能。

## 主要特性

### 1. 实时搜索
- **输入即搜索**：用户输入时自动生成搜索建议
- **多字段搜索**：支持按姓名、地区、专业领域搜索
- **智能匹配**：模糊匹配，提高搜索准确性

### 2. 搜索建议
- **智能提示**：根据输入内容生成相关建议
- **数据来源**：基于现有咨询师数据生成
- **限制数量**：最多显示5条建议，避免界面混乱

### 3. 搜索历史
- **自动保存**：每次搜索自动保存到历史记录
- **去重处理**：避免重复的搜索记录
- **容量限制**：最多保存10条搜索历史
- **一键清空**：支持清空所有搜索历史

### 4. 搜索结果
- **实时显示**：搜索结果立即显示在咨询师列表中
- **数量提示**：显示找到的咨询师数量
- **自动恢复**：3秒后自动恢复原始列表
- **无结果提示**：当没有搜索结果时显示友好提示

## 使用方法

### 基本搜索
1. 在搜索框中输入关键词
2. 支持搜索咨询师姓名、地区、专业领域
3. 点击搜索图标或按回车键执行搜索

### 使用搜索建议
1. 输入关键词时会自动显示搜索建议
2. 点击建议项可直接执行搜索
3. 建议基于现有数据智能生成

### 使用搜索历史
1. 点击搜索框时显示搜索历史
2. 点击历史记录可快速重复搜索
3. 点击"清空"按钮可清除所有历史

## 样式特点

### 搜索栏
- 深蓝色背景，白色边框

## 用户体验优化

### 1. 延迟隐藏
- 建议面板延迟200ms隐藏
- 给用户足够时间点击建议项

### 2. 智能提示
- 空输入时显示搜索历史
- 有输入时显示搜索建议
- 避免无意义的提示

### 3. 状态反馈
- 搜索成功显示结果数量
- 无结果时显示友好提示
- 操作结果都有相应的反馈
