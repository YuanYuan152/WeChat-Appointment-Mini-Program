# 图标文件说明

此目录需要放置以下图标文件：

## 必需图标
- `home.png` - 首页图标（未选中）
- `home-active.png` - 首页图标（选中）
- `consultant.png` - 咨询师图标（未选中）
- `consultant-active.png` - 咨询师图标（选中）
- `user.png` - 用户图标（未选中）
- `user-active.png` - 用户图标（选中）

## 其他图标
- `banner1.jpg` - 轮播图1
- `banner2.jpg` - 轮播图2
- `doctor1.jpg` - 医生头像1
- `doctor2.jpg` - 医生头像2
- `default-doctor.png` - 默认医生头像
- `default-avatar.png` - 默认用户头像

## 图标规格建议
- TabBar图标: 81x81px (3倍图)
- 头像图标: 120x120px
- 轮播图: 750x400px
