1. 进入与导航

EAP 网站可直接从浏览器访问，也可从微信小程序“心理测评”等入口打开。

公开访问

无需登录即可使用

  • 浏览首页、心理图文、问答、故事和音频。
  • 查看咨询师列表与介绍。
  • 浏览专业测评和趣味测评列表。
需要登录

登录后才能使用

  • 开始测评、保存报告和查看历史报告。
  • 创建预约、支付、查看预约和消息。
  • 收藏咨询师、提交反馈和退款豁免申请。

2. 公开内容浏览

主要用于了解心理知识、机构服务与咨询相关内容。

功能入口操作顺序结果
心理图文首页 → 心理图文进入列表 → 选择文章 → 阅读章节内容查看完整文章与相关推荐
心理问答首页 → 心理问答浏览问题 → 点击感兴趣的问题查看来访困惑与专业解答
我们的故事首页 → 我们的故事选择来访故事、学员故事或咨询师手记 → 阅读详情了解真实经历与机构理念
心理音画首页 → 心理音画选择节目 → 播放、暂停或切换音频在线收听心理音频内容
内容管理边界：EAP 的图文、问答、故事和音频当前主要来自站点内置内容，不等同于 Web 管理后台的“小程序内容管理”。

3. 注册与登录

网站账号与微信小程序共用业务账号数据，手机号一致时可识别为同一用户。

注册入口

网站右上角 / 导航栏 → 注册
填写手机号输入本人可用手机号。
选择验证方式按页面使用验证码或设置密码。
提交注册完成校验后建立账号并登录。

登录入口

网站右上角 / 受保护功能拦截页 → 登录
输入手机号使用已注册或小程序绑定的手机号。
完成验证输入验证码或密码。
返回原功能登录成功后继续预约、测评或查看记录。

4. 预约咨询

入口集中在“电话咨询/预约咨询”模块；预约、支付和取消规则与小程序共用后端。

4.1 浏览并选择咨询师

顶部导航 → 预约咨询 → 咨询师列表 → 咨询师详情
浏览或搜索咨询师查看姓名、方向、介绍和价格信息。
进入咨询师详情确认专业介绍、咨询中心和可预约安排。
收藏或开始预约收藏需要登录；预约会进入时段选择。

4.2 创建预约

确认登录状态未登录时先完成登录。
选择中心与时间选择杨浦、浦东或视频，以及可预约开始时间。
填写首次预约信息按页面确认成年状态、紧急联系人等信息。
阅读并签署协议确认心理咨询协议并完成手写签名。
确认订单并支付核对咨询师、时间、地点和金额后支付。
查看支付结果支付成功后生成咨询单，可在“我的预约”查看。
时间规则：每次预约为 50 分钟咨询加 10 分钟打扫，总占用 60 分钟；可预约时间以系统实时返回为准。

5. 我的预约、消息与反馈

我的预约

个人中心 → 我的预约
  1. 选择未完成、已完成、已反馈或已取消分类。
  2. 点击记录查看咨询师、时间、地点和状态。
  3. 待支付订单进入支付；可取消记录按页面规则操作。
  4. 已完成咨询可进入反馈页面。

我的消息

个人中心 → 我的消息
  1. 查看未读角标和消息列表。
  2. 打开预约、取消、退款或代理预约消息。
  3. 点击消息内操作按钮进入关联订单或预约。
  4. 阅读后消息更新为已读。

咨询反馈

我的预约 → 已完成 → 去反馈
  1. 选择目标达成和议题节奏评分。
  2. 勾选需要改进的方面。
  3. 提交后记录进入“已反馈”。

退款豁免申请

我的预约 → 取消/退款 → 申请豁免
  1. 确认当前不满足常规退款条件。
  2. 填写特殊情况原因并按页面上传材料。
  3. 提交后等待管理后台审核。
  4. 从消息或预约记录查看结果。

6. 心理测评

专业测评和趣味测评都可浏览，但开始作答和保存报告需要来访者账号登录。

顶部导航 / 首页 → 心理测评 → 专业测评或趣味测评 → 选择量表
选择量表查看量表介绍、预计题量和适用说明。
登录并确认须知专业测评还需阅读并同意当前隐私保护协议。
逐题作答按提示选择答案；本地可保留未完成进度。
补充人口学信息在结果提交前填写量表要求的必填信息。
提交报告系统计分并保存本次量表版本和结果快照。
查看结果查看总分、维度、解释、建议和可视化内容。
适用角色：测评报告提交、历史查看和删除面向来访者账号。员工角色不应使用后台工作账号代替来访者完成测评。

7. 我的报告、下载与分享

查看历史报告

心理测评 → 我的报告，或个人中心 → 我的测评
  1. 登录后进入报告列表。
  2. 按完成时间选择一份报告。
  3. 查看提交时的量表版本和结果快照。
  4. 按页面提供的删除功能删除本人报告；删除不可恢复。

下载与分享

量表详情或结果页 → 分享 / 下载
  1. 选择下载 PDF、生成邀请海报或二维码。
  2. 分享二维码只指向对应量表，不包含个人报告内容。
  3. 扫码者登录后可开始该量表。
  4. 分享配置缺失时，分享按钮会被禁用。

入口功能操作

9. 业务规则与限制

取消与退款

  • 距咨询开始超过 24 小时取消，按规则可全额退款。
  • 24 小时内、咨询已开始或已结束，通常不予全额退款。
  • 特殊情况可提交退款豁免，由后台审核。

报告版本

  • 报告保存提交时的量表版本快照。
  • 后台后续更新量表，不会覆盖历史报告。
  • 测评结果仅供参考，不能替代专业诊断。

网络与浏览器

  • 正式环境必须通过可访问的 HTTPS 地址打开。
  • 登录失效时重新登录后再继续操作。
  • 支付结果以订单最终状态为准，避免重复支付。

数据与隐私

  • 仅使用本人账号填写和查看测评。
  • 不要通过公开渠道发送个人报告截图或敏感信息。
  • 删除报告前确认已完成必要备份。

10. 常见问题

为什么点击开始测评后要求登录？
量表报告需要绑定来访者账号，便于保存历史报告和保护数据访问权限。
为什么分享按钮不可用？
分享依赖后台分享密钥和 EAP 公网地址。配置缺失时，浏览、答题和报告仍可能正常，但分享入口会停用。
取消预约后为什么没有自动退款？
请先确认距离咨询开始是否超过 24 小时。未满足常规退款条件时需要提交退款豁免申请并等待审核。
为什么历史报告和现在的量表文案不同？
历史报告固定使用提交时的量表版本快照，后台新版本不会覆盖过去报告。
