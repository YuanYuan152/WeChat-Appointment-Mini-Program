分角色功能手册

面向咨询助理、咨询主任、管理员和咨询师。来访用户不直接登录本后台，因此用户部分说明后台人员如何处理用户相关业务，并指明用户实际操作入口。

通用：登录与页面导航

当前登录边界：admin-web 使用已登记员工手机号和短信验证码登录，仅咨询师、咨询助理、咨询主任和管理员可进入；员工账号由管理员预先创建，不开放自助注册。生产使用前必须完成腾讯云短信真实发送验收。

登录后的默认首页

角色默认进入原因
管理员 Admin总览查看运营指标和待办
咨询主任 Ops总览处理日常运营
咨询助理 Assistant我的消息从待办消息开始协作
咨询师 Counselor个人看板查看本人业务数据

通用操作方式

  1. 从左侧分组菜单选择模块。
  2. 先使用顶部筛选项缩小数据范围。
  3. 点击表格行或“查看”进入详情。
  4. 新增、编辑、审核等操作通常在弹窗中完成。
  5. 提交成功后返回列表并刷新确认。

后台管理者：三种角色权限

后台管理者包括咨询助理、咨询主任和管理员。

模块咨询助理咨询主任管理员
总览无有有
消息、代理预约、审核、反馈有有有
内容管理有有有
量表管理无编辑权限有有
量表结果可看摘要，不看原始逐题答案可看完整报告可看完整报告
排期、咨询室、调价、记录有有有
用户与角色管理授权范围内低层角色管理助理、咨询师和用户权限最高
单账号单角色：更换角色会替换原角色，不是给账号增加一个可切换角色。同级不可互相管理，低级别不能管理高级别。

后台管理者：总览与我的消息

总览
入口左侧菜单 → 工作台 → 总览（管理员、咨询主任）
  1. 查看待处理豁免、咨询室占用、缺失咨询记录等摘要。
  2. 查看未读或重要消息。
  3. 点击统计卡片或待办项进入对应模块。
  4. 在目标模块完成处理后返回总览刷新。
我的消息
入口左侧菜单 → 工作台 → 我的消息
  1. 选择消息类型、已读状态或输入关键词。
  2. 打开新增预约、请假、豁免、风险或代理预约消息。
  3. 查看结构化详情。
  4. 点击“前往处理”进入审核、记录或排期页。
  5. 处理后将消息标记为已读。

后台管理者：用户、角色与来访/咨询师管理

用户与角色
入口权限管理 → 用户与角色
  1. 按手机号或姓名搜索账号。
  2. 点击新增，填写手机号、姓名和目标角色。
  3. 来访选择来源；咨询师选择公益或专业类型。
  4. 提交后检查唯一角色是否正确。
  5. 更换或删除前确认业务数据保护提示。
来访管理
入口用户管理 → 来访管理
  1. 搜索来访并打开详情。
  2. 查看资料、订单、预约、退款、豁免和备注。
  3. 点击绑定咨询师，选择目标咨询师并确认。
  4. 需要时从详情进入代理预约或量表结果。
  5. 保存内部备注。
咨询师管理
入口用户管理 → 咨询师管理
  1. 搜索咨询师并打开详情。
  2. 查看资料、排期、咨询、收入和记录摘要。
  3. 按权限编辑对外介绍资料。
  4. 查看或调整定价相关信息。
  5. 维护仅工作人员可见的备注。
绑定影响：首次绑定、更换或解除签约咨询师会影响来访签约状态。完成协议并支付当前绑定咨询师的首单后，才进入已签约状态。

后台管理者：代理预约

入口一工作台 → 代理预约　　入口二来访管理 → 来访详情 → 代理预约 / 再约一单
选择来访搜索姓名或手机号；系统自动带出绑定咨询师。
处理未绑定情况如果没有绑定咨询师，先在弹窗完成绑定。
查看排期使用普通列表或日历查看当前咨询师未来安排。
打开“代理预约”弹窗系统再次校验来访、咨询师和签约条件。
选择中心、日期和开始时间支持整点、半点；每次固定占用 60 分钟。
选择房间与协议实体咨询必选房间；未签约来访选择待签协议。
推送待支付订单来访在小程序或 EAP 完成签约和支付。
跟踪订单支付后预约生效；超时未支付则释放资源。

后台管理者：审核、反馈与咨询记录

用户豁免审核

入口业务处理 → 审核管理 → 用户豁免
  1. 选择待审核。
  2. 打开申请，核对来访、咨询、金额、原因和材料。
  3. 判断是否允许特殊退款。
  4. 点击通过，或填写拒绝理由后驳回。
  5. 确认列表状态与退款结果。

咨询师请假审核

入口业务处理 → 审核管理 → 咨询师请假
  1. 打开待审核请假。
  2. 核对原因、截图和受影响来访。
  3. 查看通过后的预约取消与退款影响。
  4. 选择通过或拒绝。
  5. 确认相关预约和消息已更新。

咨询记录与修改审核

入口业务处理 → 咨询记录
  1. 按咨询师查看已完成、已写和缺失数量。
  2. 进入咨询师明细，再打开单条记录。
  3. 查看记录内容和历史版本。
  4. 对待审修改申请核对原内容与新内容。
  5. 通过后新版本生效；驳回需填写理由。

咨询反馈

入口业务处理 → 咨询反馈
  1. 按关键词或状态筛选。
  2. 查看来访、咨询师、评分和改进项。
  3. 结合咨询记录按机构流程处理。
  4. 完成后更新相应处理状态或备注。

后台管理者：排期、咨询室与调价

排期情况
入口运营配置 → 排期情况
  1. 选择时间范围或咨询师。
  2. 查看排期列表和日历。
  3. 识别开放、待支付、已预约、完成、请假状态。
  4. 点击记录查看详细占用信息。
咨询室情况
入口运营配置 → 咨询室情况
  1. 选择中心、日期和房间。
  2. 按半小时查看占用来访。
  3. 新增或编辑房间资料。
  4. 批量设置时段可用/停用。
  5. 为已预约咨询更换可用房间。
调价管理
入口运营配置 → 调价管理
  1. 搜索并选择咨询师。
  2. 修改统一基础价或默认分成。
  3. 批量调整前先查看预览。
  4. 进入个体来访调价设置特殊价格和分成。
  5. 保存后核对生效范围。
房间时间规则：后台按半小时维护状态，一次 50 分钟咨询加 10 分钟打扫会占用两个连续半小时段。

后台管理者：量表与报告

量表管理 · Ops/Admin
入口运营配置 → 量表管理
  1. 选择新增量表或打开现有量表。
  2. 编辑基本信息、题目、选项、计分、结果模板和图片。
  3. 保存草稿并处理页面校验错误。
  4. 确认无误后发布，生成新的不可覆盖版本。
  5. 需要下线时归档；需要复用历史内容时恢复为新草稿。
量表结果
入口运营配置 → 量表结果；或 来访详情 → 查看量表结果
  1. 按来访、量表、类别、来源或日期筛选。
  2. 打开报告查看提交时快照。
  3. 咨询助理查看摘要；咨询主任和管理员按权限查看完整答案。
  4. 查看敏感原始答案时系统记录审计。
分享统计
入口量表管理 → 目标量表 → 分享统计
  1. 选择统计周期。
  2. 查看扫码总量和近似独立访问。
  3. 查看分享归因完成数及同周期完成比例。
  4. 结合量表状态和推广活动分析结果。
历史版本
入口量表管理 → 目标量表 → 历史版本
  1. 选择版本并查看发布时间和内容。
  2. 确认需要恢复的版本。
  3. 点击恢复，系统创建新草稿。
  4. 重新校验和发布，不会覆盖历史报告。

后台管理者：内容、数据导入与操作记录

内容管理

入口运营配置 → 内容管理
  1. 选择 Banner、活动或文章。
  2. 新增或打开已有内容。
  3. 填写文案、图片和展示信息。
  4. 保存并在小程序端确认。

此模块主要服务小程序，不会实时修改 EAP 的静态图文。

数据导入

入口业务处理 → 数据导入
  1. 准备符合固定表头的 Excel 文件。
  2. 上传 .xlsx。
  3. 确认导入范围并执行。
  4. 逐行查看已导入、已跳过或失败原因。

操作记录

入口业务处理 → 操作记录
  1. 选择操作类型、角色、操作人和时间范围。
  2. 输入关键词筛选。
  3. 查看订单、预约、审核、排期、房间等业务痕迹。
  4. 按关联对象继续核查。

咨询师：个人看板与明细

咨询师登录后台后默认进入个人看板，只能访问本人相关业务。

个人看板

入口咨询师工作台 → 个人看板
  1. 选择本月、近 90 天、近半年或全部。
  2. 查看完成订单数、订单收入、个人收入、记录和预约数量。
  3. 点击统计卡片进入对应明细。

订单与咨询明细

入口咨询师工作台 → 订单明细 / 咨询明细
  1. 设置时间或状态筛选。
  2. 查看已完成订单、收入和咨询记录。
  3. 打开单条记录核对来访、时间和状态。

咨询师：我的排期、请假与代理预约

新增排期

入口咨询师工作台 → 我的排期 → 新增排期
  1. 选择中心和日期。
  2. 选择整点或半点开始时间。
  3. 确认咨询室偏好。
  4. 提交后在列表或日历中确认。

取消或请假

入口我的排期 → 目标时段 → 取消 / 请假
  1. 无预约时可填写原因后取消。
  2. 已有预约时填写请假原因并按要求提交材料。
  3. 等待后台管理者审核。
  4. 通过后取消受影响预约并处理退款。

咨询师代理预约

入口我的排期 → 代理预约
  1. 选择已绑定本人且符合条件的来访。
  2. 选择中心、日期、开始时间和房间。
  3. 确认后推送待支付订单。
  4. 等待来访签约和支付。

查看排期状态

入口我的排期 → 普通模式 / 日历模式
  1. 选择日期范围。
  2. 查看开放、待支付、已预约、已完成、请假和过期。
  3. 点击时段进入咨询或记录操作。

咨询师：填写与修改咨询记录

入口咨询师工作台 → 填写咨询记录
选择已完成咨询从待填写列表进入。
填写结构化记录主观、客观、评估、咨询要点和风险评估。
检查必填项并提交提交后形成记录版本。
需要修改时申请打开原记录，填写新内容和修改原因。
等待审核咨询主任或管理员通过后新版本生效。

来访用户：Web 后台访问边界

来访用户不直接登录 admin-web，也不应获得后台菜单权限。

用户实际操作入口

  • 微信小程序：预约、支付、消息、取消、反馈和资料。
  • EAP 网站：内容、预约、心理测评、报告和个人中心。
  • 详细操作分别查看《微信小程序功能手册》和《EAP 网站功能手册》。

后台保存的用户相关信息

  • 账号与个人资料。
  • 签约咨询师、订单、预约和退款。
  • 咨询反馈、量表报告和内部工作人员备注。
  • 访问受角色权限和敏感数据规则限制。

用户相关业务：后台人员代办顺序

用户需求后台入口处理顺序用户后续动作
首次预约来访管理 → 来访详情确认资料 → 绑定咨询师 → 代理预约 → 推送订单在小程序/EAP 签约并支付
特殊退款审核管理 → 用户豁免查看申请 → 核对规则和材料 → 通过/拒绝从消息查看结果

常见问题

为什么咨询助理登录后看不到“总览”？
总览仅向咨询主任和管理员开放。咨询助理默认进入“我的消息”，从消息和授权菜单处理业务。
为什么无法给账号增加第二个角色？
系统采用单账号单角色，更换角色会替换原角色，不提供多角色切换。
为什么代理预约不能选择咨询师？
代理预约默认使用来访当前绑定咨询师。需要更换时先返回来访详情调整绑定关系，并注意签约状态会被重置。
为什么咨询助理看不到报告原始答案？
原始逐题答案属于敏感数据，仅咨询主任和管理员按权限查看；相关访问会记录审计。
为什么 EAP 文章没有随内容管理更新？
Web 后台内容管理主要服务小程序。EAP 图文、问答、故事和音频当前主要使用站点内置内容。
