后台管理者：角色与工作台

咨询助理 Assistant、咨询主任 Ops、管理员 Admin 共用移动管理工作台，但可见权限不同。

主入口底部 Tab“工作台” → 自动进入“运营工作台”
功能咨询助理咨询主任管理员
排期、咨询室、审批、用户、代理预约可用可用可用
运营看板不可见可用可用
系统设置（如代理订单有效期）不可见不可见可用
角色管理只能管理授权范围内角色可管理助理、咨询师和用户权限最高
代码中保留一套独立助理任务/风险页面，但默认 Tab 实际进入统一管理工作台，本手册以默认入口为准。

后台管理者：排期与咨询室

排期情况

查看咨询师排期

入口工作台 → 排期情况 → 选择咨询师
  1. 在列表中查看咨询师未来排期摘要。
  2. 点击咨询师进入排期详情。
  3. 切换普通模式或日历模式。
  4. 按日期查看开放、待支付、已预约、已完成、请假或过期时段。
  5. 点击时段查看来访、地点、咨询室及记录状态。
咨询室情况

查看与维护咨询室

入口工作台 → 咨询室情况 → 选择中心和房间
  1. 选择查询日期和半小时时间点。
  2. 查看房间可用、停用或正在使用状态。
  3. 进入房间详情查看未来时段及占用来访。
  4. 按权限调整可用/停用状态，或为已预约记录更换房间。
  5. 保存后重新查询确认结果。
占用规则：一次预约为 50 分钟咨询加 10 分钟打扫，咨询室视图按半小时显示，因此会占用连续两个显示段。

后台管理者：审批、用户与业务监管

审批管理
入口工作台 → 审批管理
  1. 选择退款申请或咨询师请假。
  2. 选择“待审核”并打开详情。
  3. 核对人员、预约、原因、材料和退款影响。
  4. 点击通过或拒绝；拒绝时填写理由。
  5. 返回列表确认状态，相关人员会收到消息。
用户与角色
入口工作台 → 用户管理 / 角色&权限绑定
  1. 按姓名或手机号搜索账号。
  2. 打开来访或咨询师详情。
  3. 查看资料、订单、预约、备注及绑定关系。
  4. 按权限创建账号、绑定唯一角色或维护咨询师关系。
  5. 保存后确认角色和资料状态。
咨询记录
入口工作台 → 咨询记录 / 咨询记录修改审核
  1. 查看咨询师记录填写概览。
  2. 进入咨询师或单条记录详情。
  3. 查看记录内容、版本和风险信息。
  4. 对修改申请执行通过或驳回。
  5. 风险上报按机构线下制度继续跟进。

后台管理者：代理预约

入口工作台 → 代理预约；或 用户管理 → 来访详情 → 代理预约
搜索并选择来访系统显示签约状态和绑定咨询师；未绑定时先完成绑定。
打开代理预约确认来访与咨询师关系正确。
选择预约中心与日期选择实体中心或视频咨询。
选择开始时间支持整点和半点，系统校验咨询师与房间冲突。
选择咨询室或协议实体咨询必选房间；未签约来访需选待签协议。
推送订单来访收到待支付订单，支付前该时段显示待支付。
跟踪结果来访有效期内支付后变为已预约；超时则释放资源。

咨询师：进入个人工作台

咨询师登录后，底部第三个 Tab 显示“工作台”。

主入口底部“工作台” → 咨询师工作台

咨询排期面板

  • 查看普通列表或日历。
  • 新增排期、取消空闲排期。
  • 对已预约时段提交请假。
  • 为绑定来访发起代理预约。
  • 从已完成时段进入咨询记录。

个人看板面板

  • 选择统计时间范围。
  • 查看完成订单、收入、预约和咨询记录数量。
  • 点击指标进入相应明细。
  • 从个人中心维护咨询师资料。

咨询师：新增排期、取消与请假

新增排期

入口工作台 → 咨询排期 → “+ 新建排期”
选中心选择实体中心或视频。
选日期只能选择允许的未来日期。
选开始时间支持整点、半点，固定 50+10 分钟。
确认咨询室偏好系统检查房间与排期冲突。
提交成功后时段出现在排期日历。

取消排期或请假

入口工作台 → 咨询排期 → 选择目标时段
  1. 未被预约的排期：点击取消，填写原因并确认。
  2. 已经有来访预约：点击请假，填写原因。
  3. 按页面要求上传沟通截图。
  4. 提交后状态进入请假审核。
  5. 审核通过后受影响预约取消并按规则退款；驳回则原预约保持。

咨询师代理预约

入口工作台 → 咨询排期 → “代理预约”
选择来访仅显示已绑定本人且符合条件的来访。
选择中心、日期和时间可使用已有开放排期或允许的新时段。
选择咨询室视频咨询无需实体房间。
推送订单来访收到消息后自行签约、支付。

咨询师：咨询单与咨询记录

填写咨询记录

入口工作台 → 已完成时段 → 填写咨询记录；或“我的” → 咨询记录填写
  1. 打开对应咨询，确认来访与时间。
  2. 填写主观描述、客观描述、评估和咨询要点。
  3. 完成风险评估等必填内容。
  4. 提交记录并确认成功。
  5. 高风险内容会触发管理侧风险提醒。

修改已提交记录

入口工作台 → 查看咨询记录 → 申请修改
  1. 打开原记录和历史版本。
  2. 进入修改模式，填写修订内容及原因。
  3. 提交修改申请。
  4. 等待咨询主任或管理员审核。
  5. 通过后新版本生效；驳回则保留原记录。

来访用户：首页与咨询师浏览

用户无需登录即可浏览公开内容，预约、订单和记录功能需要登录。

首页

入口底部“首页”
  1. 查看 Banner、推荐咨询师、活动和文章。
  2. 点击搜索查找咨询师或内容。
  3. 点击卡片进入对应详情。

咨询师列表

入口底部“心理咨询”
  1. 浏览咨询师列表。
  2. 使用页面筛选或搜索。
  3. 点击咨询师查看详细介绍、中心、价格和排期。

收藏咨询师

入口咨询师详情 → 收藏；或“我的” → 我的收藏
  1. 登录后点击收藏。
  2. 在我的收藏查看已收藏咨询师。
  3. 再次点击可取消收藏。

来访用户：首次预约、自助续约与支付

首次预约限制：首次预约需要联系咨询助理，由工作人员完成咨询师绑定、签约及首单流程。完成首单后，才可自助预约当前签约咨询师。

自助预约入口与步骤

入口底部“心理咨询” → 当前签约咨询师详情 → 可约时间
确认预约权限系统校验已绑定并签约当前咨询师。
选择中心与开始时间从实时可用安排中选择。
核对订单信息确认咨询师、时间、地点和金额。
签署或确认协议首次相关流程按页面填写紧急联系人和签名。
完成微信支付支付成功后排期变为已预约。
查看预约从底部“预约记录”或“我的订单”查看。

支付工作人员推送的代理订单

入口“我的消息” → 待支付预约；或“我的” → 我的订单 → 待支付
  1. 打开代理预约消息或待支付订单。
  2. 核对咨询师、日期、时间、中心和金额。
  3. 未签约时按页面完成协议确认和签名。
  4. 在订单有效期内完成支付。
  5. 支付成功后查看预约记录；超时未支付会释放时段。

来访用户：预约记录、取消、退款与反馈

查看预约记录

入口底部“预约记录”
  1. 选择未完成、已完成、已反馈或已取消。
  2. 点击记录查看时间、地点、咨询师和状态。
  3. 待支付记录点击“去支付”。
  4. 已完成记录点击“去反馈”。

取消与退款

入口预约记录 → 未完成 → 取消预约
  1. 打开待取消记录并查看退款提示。
  2. 距开始超过 24 小时，按常规流程确认取消。
  3. 24 小时内通常不退款，可选择申请退款豁免。
  4. 填写原因和材料后提交审核。
  5. 从消息或已取消记录查看结果。

咨询反馈

入口预约记录 → 已完成 → 去反馈
  1. 填写目标达成评分。
  2. 填写议题节奏评分。
  3. 选择改进项并提交。
  4. 提交后记录进入已反馈分类。

订单详情

入口“我的” → 我的订单 → 选择订单
  1. 查看待支付、已支付和已取消订单。
  2. 检查金额、有效期和关联预约。
  3. 待支付订单可继续支付。
  4. 已取消订单查看取消或退款说明。

状态含义用户操作员工操作

常见问题

为什么用户无法直接选择咨询师时间？
首次预约需联系咨询助理完成绑定、签约和首单支付。后续只能自助预约当前签约咨询师。
为什么代理预约按钮不可用？
先确认已选择来访、来访已绑定咨询师，并选择可用中心、日期、开始时间和咨询室；未签约时还需选择协议。
为什么房间看起来空闲却不能选择？
系统按完整 60 分钟窗口校验两个连续半小时时段；其中任一时段停用或冲突都会禁止选择。
为什么员工看不到运营看板或系统设置？
咨询助理不能查看运营看板；系统设置仅管理员可用。菜单按唯一角色权限显示。
