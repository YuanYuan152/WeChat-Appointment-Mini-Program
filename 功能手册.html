01

平台概览

同一套业务后端连接三个用户入口，各入口承担不同工作。

微信小程序

移动端

来访者使用的主要入口，也提供咨询师、助理、运营和管理员移动工作台。

  • 咨询师浏览、预约、支付与记录
  • 订单、消息、资料和服务通知
  • 按账号角色动态进入对应工作台

Web 管理后台

电脑端

面向管理员、运营、咨询助理和咨询师的重后台，提高批量查询与业务处理效率。

  • 来访、咨询师、排期和咨询室管理
  • 代理预约、审核、定价和业务记录
  • 量表、报告、分享统计与内容管理

EAP 心理网站

Web 端

面向公众和已登录用户的内容、心理测评及咨询服务网站。

  • 心理图文、问答、故事和音频
  • 专业量表、趣味测评和历史报告
  • 手机号登录、咨询预约与个人中心
02

登录、账号与个人资料

不同入口可使用不同登录方式，但账号数据由同一业务系统管理。

微信小程序

微信一键登录

  1. 阅读并勾选用户服务协议与隐私政策。
  2. 点击“微信一键登录”，授权微信身份和手机号。
  3. 新用户按提示完善昵称等资料。
  4. 按需授权服务通知，用于预约、审核和订单提醒。
EAP 网站

手机号登录或注册

  • 统一使用手机号短信验证码，不再提供密码登录或注册。
  • 手机号一致时，可与小程序账号识别为同一用户。
  • 登录后可查看测评报告、咨询记录、消息和个人资料。
单账号单角色 当前系统中一个账号只保留一个角色，不支持自行切换角色。系统根据该唯一角色展示工作台与底部导航；需要变更身份时，应由有权限的工作人员在用户与角色管理中更换角色。
Web 管理后台登录边界 admin-web 使用已登记员工手机号和短信验证码登录，仅咨询师、咨询助理、咨询主任和管理员可进入；员工账号由管理员预先创建，不开放自助注册。

04

来访者功能

从了解咨询师到预约、支付、完成咨询和后续反馈的完整移动服务。

首页与内容浏览

  • 查看首页推荐、活动、文章和主题内容。
  • 使用搜索查找咨询师或内容。
  • 浏览心理图文、往期精华、联系我们等公开页面。

咨询师浏览

  • 查看咨询师列表、详情、介绍和可预约时间。
  • 收藏感兴趣的咨询师。
  • 从咨询师详情进入预约流程。

预约与支付

  • 首次预约需联系咨询助理完成咨询师绑定、签约和首单支付。
  • 完成首单后，才可自助预约当前签约咨询师。
  • 选择日期、开始时间、咨询形式及可用资源。
  • 确认信息并签署适用的咨询协议。
  • 创建订单并完成微信支付；查看支付结果。

订单与预约记录

  • 查看待支付、已支付和已取消订单。
  • 查看未完成、已完成和已取消预约。
  • 代理预约订单可从消息或订单列表继续支付。

取消、退款与反馈

  • 距咨询开始超过 24 小时取消，可按规则全额退款。
  • 24 小时内取消或爽约通常不退款，特殊情况可提交退款豁免申请。
  • 咨询结束后填写咨询反馈并查看处理状态。

个人中心

  • 编辑个人资料和心理登记表。
  • 查看消息、收藏、测评报告和服务通知设置。
  • 查看用户协议、隐私政策及提交意见反馈。
05

咨询师功能

围绕个人排期、预约执行、记录填写和业务统计开展工作。

工作台与统计

小程序 / Web
  • 查看今日安排、待处理事项、预约和消息。
  • 查看个人咨询数据、完成订单和收入明细。
  • 按时间范围查看咨询与订单统计。

排期管理

核心
  • 按日期选择整点或半点开始时间新建排期。
  • 查看开放、已预约、已完成、请假和过期排期。
  • 未被预约的排期可按规则取消。
  • 已影响预约时通过请假流程提交审核。

代理预约

受限操作
  • 仅为已绑定本人且符合条件的来访推送订单。
  • 选择中心、日期、开始时间和咨询室。
  • 可使用已有开放排期，也可在允许时新建预约时段。
  • 订单推送后由来访在有效期内签约并支付。

咨询记录

敏感数据
  • 查看本人咨询单和预约明细。
  • 咨询完成后填写咨询记录。
  • 记录提交后需要修改时发起修改申请。
  • 按业务要求进行风险标记或风险上报。
06

咨询助理功能

协助咨询团队处理任务、风险、排期协调与来访跟进。

小程序管理工作台

  • 默认与运营、管理员共用移动管理工作台。
  • 查看排期、咨询室、审批、用户和咨询记录。
  • 协助代理预约、定价、反馈与角色管理。
  • 运营看板、系统设置等高权限入口按角色隐藏。

Web 协同处理

  • 按权限查看排期、咨询室、来访和咨询师信息。
  • 参与审核管理、咨询反馈和咨询记录处理。
  • 使用代理预约、消息和运营配置等授权模块。
备用页面说明 代码中还保留独立的助理任务、风险、排期和联系记录页面，但当前默认 Tab 不会进入该子工作台。本手册以实际默认的管理工作台流程为准。
07

运营与管理员功能

Web 管理后台为主要操作入口，小程序提供移动端补充。

总览与消息

  • 查看运营指标、待办、未读消息和异常提醒。
  • 按消息类型、已读状态和关键词筛选。
  • 从消息跳转到审核、记录或排期详情。

用户与角色

  • 创建业务账号并绑定角色。
  • 维护来访来源、咨询师类型等属性。
  • 查看来访和咨询师看板、资料及内部备注。

来访管理

  • 查看资料、订单、金额、预约、退款和豁免。
  • 绑定、更换或解除咨询师。
  • 从来访详情发起代理预约或再次预约。

排期与代理预约

  • 查看咨询师排期总览、日历及状态。
  • 选择来访后自动使用其绑定咨询师。
  • 推送待支付订单，并跟踪支付和占用情况。

咨询室管理

  • 查看各中心咨询室当前状态和占用来访。
  • 按半小时查看单间咨询室时段。
  • 按半小时维护可用或停用状态。
  • 预约会占用连续两个半小时显示段。

审核管理

  • 审核退款豁免申请。
  • 审核咨询师请假及受影响预约。
  • 审核咨询记录修改申请。
  • 查看处理结果和关联消息。

定价管理

  • 维护基础价格和相关业务配置。
  • 按来访设置个性化价格调整。
  • 查看定价与抽成相关提醒。

咨询与业务记录

  • 查询咨询记录、提交状态和详情。
  • 查看咨询反馈及风险上报。
  • 查看订单、预约、请假、房间等操作记录。

内容与辅助工具

  • 维护小程序使用的 Banner、活动和文章等运营内容。
  • EAP 官网图文、问答、故事和音频当前主要使用站点内置数据，不与此处实时联动。
  • 按部署版本使用已完成订单数据导入入口。
  • 通过系统设置维护业务级参数。
高影响操作提示 角色变更、审核、定价、咨询室停用、量表发布等操作会影响真实业务。操作前应确认目标环境、对象和影响范围。
08

心理测评功能

支持量表维护、用户答题、报告保存、分享二维码与运营统计。

用户测评

  • 浏览专业测评与趣味测评列表。
  • 阅读指导语，填写人口学问题和量表题目。
  • 提交后查看即时结果、维度解释和可视化报告。
  • 登录用户可查看历史测评报告。
  • 可按页面能力下载 PDF 报告或删除本人报告；删除后不可恢复。
  • 专业量表按要求确认当前隐私同意版本。

量表生命周期

  • 新建：创建量表草稿和计分定义。
  • 编辑：校验题目、选项、维度、结果和图片。
  • 发布：生成新的不可覆盖版本，供用户使用。
  • 归档：从正常使用入口下线，但保留历史数据。
  • 恢复：把历史版本恢复为新草稿，而非覆盖旧版本。

报告与敏感数据

  • 后台可按权限查询报告列表和详情。
  • 历史报告使用提交时的量表版本和结果快照。
  • 删除、原始答案和人口学数据按角色分级授权。
  • 管理操作写入量表审计记录。

分享二维码与统计

  • 每个量表可生成带签名的分享入口和邀请海报。
  • 扫码后进入对应量表页面，不包含个人报告内容。
  • 统计扫码次数、近似独立访客、归因完成和完成比例。
  • 分享配置缺失时，浏览和答题可用，但分享按钮会停用。

核心业务流程

以下流程用于理解各角色之间的协作关系。

来访者自主预约

选择咨询师浏览详情与可预约安排。
选择开始时间支持整点和半点开始。
确认与签约核对信息并确认适用协议。
支付订单支付成功后锁定预约与资源。
咨询与反馈完成咨询后查看记录并反馈。

管理员或咨询师代理预约

选择来访必须存在合适的绑定咨询师关系。
校验签约状态未签约时选择待推送协议。
选择资源中心、日期、开始时间和咨询室。
推送订单来访收到待支付消息与订单。
来访支付有效期内支付后正式占用时段。
预约时长规则 每次预约由“50 分钟咨询 + 10 分钟打扫”组成，总占用 60 分钟。开始时间支持整点和半点；咨询室管理以半小时为单位显示，因此一次预约覆盖连续两个显示段。

咨询师请假与退款影响

提交请假填写原因并关联受影响安排。
进入审核运营或管理员查看申请详情。
通过或驳回审核决定后通知相关人员。
处理预约通过后取消受影响预约。
处理退款已支付订单按业务规则安排退款。

对象状态含义通常可执行操作

订单已取消 CANCELLED订单失效或预约已取消查看取消与退款说明
排期开放 OPEN咨询师已排期，当前可预约来访预约或代理预约
排期待支付 PENDING_PAYMENT已生成代理订单，等待来访支付等待支付或到期释放

使用边界与注意事项

区分正式业务功能、权限限制和开发联调能力。

正式业务注意事项

  • 敏感数据只应由有业务需要的授权角色查看。
  • 支付、退款、请假和审核结果以服务端最终状态为准。
  • 修改咨询师绑定关系会影响签约状态和代理预约条件。
  • 已发布量表和历史报告采用版本快照，不随新版本覆盖。

开发测试专用功能

  • 开发者入口、模拟角色登录和 dev_* 登录码。
  • API 测试页面、Mock 短信和模拟支付。
  • 开发者工具中的“不校验合法域名”。
  • 这些能力不应作为正式生产功能写入对外操作流程。
13

常见问题

遇到问题时，先确认当前角色、环境和业务状态。

为什么看不到某个菜单或功能？
功能菜单会按照账号的唯一角色过滤。请确认账号已绑定正确角色；当前不支持账号自行切换角色，如需变更应由有权限的工作人员调整。部分功能仅管理员或运营可用。
为什么代理预约按钮不可用？
通常需要先选择来访，并确认来访已经绑定咨询师。还需选择有效日期、可预约开始时间和咨询室；未签约来访还必须选择待签署协议。
为什么时间可选但咨询室不可选？
预约会占用 60 分钟，系统会同时校验两个连续半小时时段。任一时段被占用、停用或冲突，咨询室都不可选择；视频咨询通常不要求实体咨询室。
为什么分享量表按钮被禁用？
分享功能依赖后台分享密钥和 EAP 公网地址。配置缺失时仍可浏览和答题，但系统会主动禁用二维码分享。
为什么体验版提示网络连接失败？
确认发布包使用可从手机访问的 HTTPS 后端地址，微信公众平台已配置 request 合法域名，且上传后已把新版本设置为体验版。发布包不能使用 localhost 或 127.0.0.1。
咨询记录提交后还能直接修改吗？
已提交记录通常不能任意覆盖。咨询师需要发起修改申请，由授权人员审核，以保留业务追踪和审计记录。
